# Digital RTL & Memory Systems Projects

## About
Undergraduate research-oriented RTL design projects focusing on control logic, cache and CDC behaviors.

## Projects
Each project below includes description, tools used, and what I implemented.

### 1) Direct-Mapped Cache
- Objective: Basic memory hierarchy exploration.
- Features: Tag/index/offset decode, valid & dirty bits(write-back and write-allocate policy), hit/miss logic.
- Skills: FSM control, timing correctness, hit/miss behavior via simulation.

### 2) Asynchronous FIFO
- Objective: Safe FIFO across two clocks.
- Features: Gray-coded pointers, synchronizers, full/empty logic.
- Skills: CDC handling, metastability management.

### 3) 8-bit Booth Multiplier on FPGA
- Synthesized on Basys 3.
- FSM control for multiplication cycles.

### 4) RTL Datapath Modules
- Barrel shifter, CLAs, CSAs, AXI4 stream protocol, line buffers, synchronous FIFOs.
